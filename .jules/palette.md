## 2024-08-11 - Group Hover Accessibility
**Learning:** When using `group-hover:opacity-100` to show interactive elements on hover, ensure the parent element has the `group` class. Also, must add `focus-visible:opacity-100` so keyboard users can discover the element.
**Action:** Always verify parent `group` classes exist when using `group-hover` and enforce keyboard discoverability with `focus-visible`.
