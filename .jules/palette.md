
## 2026-09-21 - Kwil Focus Ring Pattern
**Learning:** The application uses a specific combination of Tailwind classes (focus-visible:ring-2 focus-visible:ring-[#00FF9C] focus-visible:outline-none focus-visible:ring-offset-2 focus-visible:ring-offset-[#050B08]) for its focus state aesthetic, which was missing from the core button component.
**Action:** Ensure all interactive elements, especially primary actions like KwilButton, apply these specific focus classes for keyboard accessibility.
