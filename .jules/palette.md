## $(date +%Y-%m-%d) - Focus Ring Pattern for Reusable Components
**Learning:** Adding `focus-visible` utility classes directly to the base styles of generic UI components (like `KwilButton`) guarantees universal accessibility across the application without polluting individual implementations. The standard pattern (`focus-visible:ring-2 focus-visible:ring-[#00FF9C] focus-visible:outline-none focus-visible:ring-offset-2 focus-visible:ring-offset-[#050B08]`) should be applied globally to all interactive elements to maintain consistency.
**Action:** When creating or modifying new reusable interactive components (buttons, switches, inputs), always inject the standard `focus-visible` Tailwind string into the base classes to enforce keyboard navigation accessibility by default.
