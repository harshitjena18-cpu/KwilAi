## 2026-10-14 - Reusable accessibility pattern for keyboard navigation
**Learning:** The application uses a standard aesthetic for focus states via Tailwind classes (`focus-visible:ring-2 focus-visible:ring-[#00FF9C] focus-visible:outline-none focus-visible:ring-offset-2 focus-visible:ring-offset-[#050B08]`) to ensure keyboard accessibility. This is a critical pattern for reusable UX in this design system.
**Action:** Always apply these standardized focus-visible classes to interactive elements like buttons and inputs when creating or modifying them.
