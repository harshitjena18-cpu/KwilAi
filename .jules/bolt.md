## 2024-05-18 - Optimize background caching with bulkWrite
**Learning:** Using `Promise.all()` to save multiple items in parallel using `Recipe.findOrCreate` (which uses `findOneAndUpdate` internally) results in N database roundtrips for N recipes, an N+1 query problem that hurts backend performance on batch operations. Mongoose `Model.bulkWrite()` is significantly faster because it groups updates into a single database call. However, Mongoose middleware and automatic timestamp creation (`timestamps: true`) are bypassed entirely during `bulkWrite`.
**Action:** Always favor `Model.bulkWrite()` for bulk database operations. When using `bulkWrite` with `upsert: true`, remember to manually validate the inputs (e.g., using `new Model(data).validateSync()`), and manually handle the creation of `createdAt` and `updatedAt` explicitly inside `$setOnInsert` and `$set`.
