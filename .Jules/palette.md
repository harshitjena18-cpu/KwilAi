## 2026-02-23 - Application-Specific Focus Pattern
**Learning:** This application standardizes focus states across inputs and switches using a specific Tailwind class combination (`focus-visible:ring-2 focus-visible:ring-[#00FF9C] focus-visible:outline-none focus-visible:ring-offset-2 focus-visible:ring-offset-[#050B08]`), but the primary Button component lacked these styles, creating an inconsistent keyboard navigation experience.
**Action:** When auditing custom UI components in a new design system, always cross-reference interactive states (like focus and hover) against the lowest-level functional components (like inputs) to ensure pattern consistency, even if the primary buttons look visually polished.
